- 镜像
```shell
sudo docker images   // 查看镜像
sudo docker rmi  <名/id>  //删除指定镜像

```

- 运行
```shell
sudo docker run 【-d】 <名/id> //重新运行容器
sudo docker ps [-a]      //查看正在运行的容器
sudo docker rm [-f] <名/id>    //删除正在运行的容器

sudo docker start <名/id>     //启动与停止运行
sudo docker stop <名/id>

sudo docker inspect  <名/id>  //查看容器信息
sudo docker logs  <名/id>  //查看容器日志
```

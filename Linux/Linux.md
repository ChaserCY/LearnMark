## 三种模式中各自可进行的操作
### 一般模式：
1. yy   数字+yy  拷贝当前行/当前及以下n行  ，按p键粘贴
2. dd  数字+dd  删除当前行/当前及以下n行
3. G  文件末行   gg  文件首行
4. u 撤销
5. 数字 + Shift + G 进行指定行跳转
### 命令模式：
1. /Hello(某单词)   查找单词，输入键盘 n ，跳转下一个查找结果
2. :set nu   /   :set nonu   显示/隐藏行号
3. :wq  保存并退出
4. :q! 和 :q   都是不保存

## at定时任务
基本介绍：
1. at命令是一次性定时计划任务，at的守护进程atd会以后台模式运行，检查作业队列来运行。
2. 默认情况下，atd守护进程每60秒检查作业队列，有作业时，会检查作业运行时间，如果时间与当前时间匹配，则运行此作业。
3. at命令是一次性定时计划任务，执行完一个任务后不再执行此任务了
4. 在使用at命令的时候，一定要保证atd进程的启动，可以使用相关指令来查看
 ps -ef | grep atd    //可以检测atd是否在运行
 5.查询任务：atq

## 服务的运行级别
- linux系统有七种运行级别（runlevel）：==常用的是级别3和5==
	 -  运行级别0：系统停机状态，系统默认运行级别不能设为0，否则不能正常启动
	- 运行级别1：单用户工作状态，root权限，用于系统维护，禁止远程登录
	- 运行级别2：多用户状态（没有NFS），不支持网络
	- 运行级别3：完全的多用户状态（有NFS），登录后进入控制台命令行模式
	- 运行级别4：系统未使用，保留
	- 运行级别5：X11控制台，登陆后进入图形GUI模式
	- 运行级别6：系统正常关闭并重启，默认运行级别不能设为6，否则不能正常启动

# 其他知识点
## sudo 的使用要点
 `sudo`的核心功能是**以指定用户（默认是 root）的权限执行单个命令**，执行完成后会回到当前用户的环境，无需切换用户身份
- 执行格式：`sudo + 你要执行的命令`（比如 `sudo vi 配置文件`、`sudo kill 进程号`）；
- 密码验证：第一次用 `sudo` 时，需要输入**你当前普通用户的密码**（输入时屏幕不会显示字符，正常输入即可），验证通过后会有 5-15 分钟的 “权限有效期”，期间再用 `sudo` 不需要重复输密码；
- 安全性：`sudo` 只会给当前命令临时授权，不会让你一直处于管理员状态，避免误操作破坏系统（比如误删系统文件）。

## 默认提示符
默认提示符的核心作用是辅助终端操作，主要功能包括：
1. **指示输入就绪**：告知用户终端已完成前序操作、处于等待命令输入的状态，是终端与用户的交互信号。
2. **区分用户身份**：通过不同符号区分权限（普通用户用`$`、超级用户`root`用`#`），提示用户当前账户的操作权限范围，避免误执行高风险操作。
3. **展示环境信息**：默认提示符通常包含用户名、主机名、当前工作目录等内容（如`user@localhost:~$`），帮助用户快速确认当前操作的系统、所在路径，减少环境混淆。

在 Linux 的 bash 环境中：
1.  普通用户的默认提示符为`$`；

## 进程的类型：
Linux 系统的**进程类型**包括交互进程（用户与系统交互的进程）、批处理进程（后台批量执行的进程）、守护进程（后台长期运行的服务进程）；而**就绪进程是进程的状态**（进程状态包括就绪、运行、等待等），并非进程类型
## 进程的状态：
- **运行态**：进程正在 CPU 上执行；
- **就绪态**：进程已准备好执行，等待 CPU 调度；
- **等待态（阻塞态）**：进程因等待资源（如 I/O、信号）而暂停执行。

## 前，后台进程：
- **前台进程**：  
    与当前终端（如命令行窗口）直接绑定，能**实时接收终端输入**（比如键盘操作），输出也直接显示在终端上。  
    例：直接执行`vim test.txt`，vim 会占用终端，你可以直接在终端里编辑文件。
    
- **后台进程**：  
    与当前终端 “解耦”，**无法直接接收终端输入**（即使输入内容也不会响应），但默认输出仍会显示在终端（可能干扰当前操作）。  
    例：执行`vim test.txt &`（后台启动 vim），此时无法直接在终端编辑，需用`fg`调回前台才能操作。
	- jobs         //可以查看后台中的程序执行

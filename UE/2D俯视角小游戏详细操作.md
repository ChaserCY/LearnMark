# 角色
## 动画
### 创建动画源
1. 右键创建： paperZD->玩家动画源
2. 进入设置：左上角创建新动画(行走和静止)->右侧细节栏最上方打勾，出现八向和四向动画序列设置->设置每个方向的播放动画(与输入映射一致)

### 创建动画蓝图(使用动画源)
1. 右键创建paperZD动画蓝图
 ![[Pasted image 20251205205607.png]]
2. 在时间图表中使用cast to 类型转换，获取角色蓝图（BP_Man）,并设置为变量方便调用角色的速度来判断动作
![[Pasted image 20251205212311.png]]
3. 处理动画：
	- 先确定动画方向
	- ![[Pasted image 20251206192158.png]]
	- 添加状态机，在状态机里分支bool来判定动画(这里只有两种状态，在里面用一个bool判断)
	- ![[Pasted image 20251206192225.png]]
	- 在角色蓝图中，找到动画组件添加动画
	- ![[Pasted image 20251206192600.png]]

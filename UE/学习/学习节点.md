### 1. Find Look at Rotation（寻找朝向旋转）
- **它的作用**：  
    这是一个“瞄准计算器”。它回答的问题是：“如果我站在 **Start（起点）**，想要看向 **Target（目标点）**，我的头应该怎么转？”
- **输入**：
    - Start：通常是玩家角色或枪口的位置。
    - Target：通常是鼠标点击的地面位置，或者敌人的位置。
        
- **输出**：  
    它返回一个 **旋转量（Rotator）**，包含三个轴的数据：(==以对应轴进行旋转的意思==)
    - **Roll (X):** 翻滚（歪头）。通常很少用到，除非你在开飞机。
    - **Pitch (Y):** 俯仰（抬头/低头）。如果目标在山上，你需要抬头；在坑里，你需要低头。
    - **Yaw (Z):** 偏航（左右水平转头）。这是控制角色东南西北方向的核心。
        
![[图片/UE/学习/学习节点/IMG-20260301171512826.png]]
### 2. Get Rotation X Vector（获取旋转的X轴向量）

- **它的作用**：  
    这是一个“方向转换器”。它回答的问题是：“如果我保持这个旋转角度，我的**正前方（X轴）**是指向世界坐标系的哪个方向？”
    
- **为什么是 X Vector？**  
    在虚幻引擎（UE）的标准里，**红色轴（X轴）永远代表物体的“正前方” (Forward)**。所以获取 X Vector，就是获取“前进方向”。
    
- **输出**：  
    它返回一个 **单位向量（Unit Vector）**，长度为1。比如 (1, 0, 0) 代表正北，(0, 1, 0) 代表正东。

![[图片/UE/学习/学习节点/IMG-20260301171512857.png]]
第二个节点意思是前面传过来的Z轴旋转，怎么旋，我就指向那个方向，并创建对应向量传给后面

## 获取控件和控件组件
- **Widget Component（左边的变量）：** 是为了让UI能在3D世界里显示出来的**载体**。
    
- **Get User Widget Object（中间的节点）：** 是为了拿到载体里面的**内容**，这样你才能修改上面的字。
- ![[图片/UE/学习/学习节点/IMG-20260301171512924.png]]
逻辑流向：

1. **伤害数字控件**：你告诉引擎，“我要操作这个3D组件”。
    
2. **获取控件**：你告诉引擎，“把这个组件里显示的那个UI界面拿给我”。
    
    - 此时，你拿到的是一个通用的‘UI界面’，引擎还不知道它是血条还是伤害数字。
        
3. **类型转换为 UI_伤害数字 (Cast to...)**：你告诉引擎，“我确定刚才拿出来的这个UI界面，就是我写的那个‘UI_伤害数字’蓝图”。
    
4. **之后（图里还没连的地方）**：一旦转换成功，你就可以从蓝色的引脚拉出线，找到那个 **Text Block（文本框）**，然后设置它的 **Text** 为具体的伤害数值（比如 50）。

## Sequence
### 1. 它是“逻辑顺序”，不是“时间顺序”

Sequence 保证的是：**在 0 号引脚的所有逻辑全部跑完之前，绝对不会开始跑 1 号引脚。**

但是，这种“跑完”指的是**非潜伏性逻辑（Instant Actions）**。

### 2. 致命陷阱：潜伏性节点 (Latent Nodes)

如果你的 Sequence 某个引脚后面接了 **Delay（延迟）**、**Timeline（时间轴）** 或 **Move Component To** 等带小闹钟图标的节点，Sequence 的表现会让你感到“逻辑混乱”：

- **发生的情况**：Sequence 会触发 0 号引脚的 Delay，**但 Delay 本身是异步的**。
    
- **后果**：Sequence 认为它已经成功把 0 号引脚的任务“发射”出去了，它**不会等待 Delay 结束**，而是会**立即执行 1 号引脚**。
    
- **现象**：你会发现 1 号引脚的内容比 0 号引脚延迟后的内容先执行了。
    

### 3. 内存和变量安全

由于 Sequence 是在同一帧内按顺序执行的，你可以安全地在 0 号引脚中**设置变量**，然后在 1 号引脚中**读取该变量**。这在蓝图中非常有用，可以避免把线连得满屏幕都是。

### 4. 什么时候用 Sequence？

- **整理逻辑线**：当一个事件后面接了太长的一串节点，用 Sequence 拆分成几块，从上往下排，代码可读性更高。
    
- **分支独立化**：例如，按下“开火”键，0 号引脚处理“减少子弹”，1 号引脚处理“播放特效”，2 号引脚处理“检查过热”。这三者逻辑互不干扰。
    

### 5. 与“宏”里的 ForEach 循环对比

- Sequence 是并列的多个出口。
    
- 如果你在 Sequence 内部执行了一个循环，Sequence 会等**整个循环彻底跑完**，才会走下一个引脚。

## Class Const
- 命名函数时的const作用，能访问的变量都只能只读，并且里面不能调用非const的函数
```cpp
class AZeroClashCharacter
{
    float Shield;
    float Health;

    // ✅ const 函数：只读取，不修改
    float GetShield() const { return Shield; }   // OK

    // ❌ const 函数中尝试修改：编译报错！
    void SetShield(float S) const { Shield = S; }  // 编译错误：不能修改成员

    // ❌ const 函数中调用非 const 函数：也报错！
    void DoSomething() const {
        ModifyHealth();   // 编译错误：不能调用非 const 成员函数
    }
    
    void ModifyHealth() { Health -= 10.f; }
};
```

## 前置声明与cpp#include
头文件用前置声明减少 \#include，避免头文件层层嵌套带来的编译爆炸；.cpp 才真正 \#include 拿完整定义，因为 cpp 只在编译这个文件时才展开，不会污染全局。

头文件只做变量/指针声明，源文件实现方法函数时，需要调用对应的方法就需要#include

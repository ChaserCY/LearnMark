### 1. Find Look at Rotation（寻找朝向旋转）
- **它的作用**：  
    这是一个“瞄准计算器”。它回答的问题是：“如果我站在 **Start（起点）**，想要看向 **Target（目标点）**，我的头应该怎么转？”
- **输入**：
    - Start：通常是玩家角色或枪口的位置。
    - Target：通常是鼠标点击的地面位置，或者敌人的位置。
        
- **输出**：  
    它返回一个 **旋转量（Rotator）**，包含三个轴的数据：(==以对应轴进行旋转的意思==)
    - **Roll (X):** 翻滚（歪头）。通常很少用到，除非你在开飞机。
    - **Pitch (Y):** 俯仰（抬头/低头）。如果目标在山上，你需要抬头；在坑里，你需要低头。
    - **Yaw (Z):** 偏航（左右水平转头）。这是控制角色东南西北方向的核心。
        
![[Pasted image 20251209164350.png]]
### 2. Get Rotation X Vector（获取旋转的X轴向量）

- **它的作用**：  
    这是一个“方向转换器”。它回答的问题是：“如果我保持这个旋转角度，我的**正前方（X轴）**是指向世界坐标系的哪个方向？”
    
- **为什么是 X Vector？**  
    在虚幻引擎（UE）的标准里，**红色轴（X轴）永远代表物体的“正前方” (Forward)**。所以获取 X Vector，就是获取“前进方向”。
    
- **输出**：  
    它返回一个 **单位向量（Unit Vector）**，长度为1。比如 (1, 0, 0) 代表正北，(0, 1, 0) 代表正东。

![[Pasted image 20251209165600.png]]
第二个节点意思是前面传过来的Z轴旋转，怎么旋，我就指向那个方向，并创建对应向量传给后面

## 获取控件和控件组件
- **Widget Component（左边的变量）：** 是为了让UI能在3D世界里显示出来的**载体**。
    
- **Get User Widget Object（中间的节点）：** 是为了拿到载体里面的**内容**，这样你才能修改上面的字。
- ![[Pasted image 20251209195711.png]]
逻辑流向：

1. **伤害数字控件**：你告诉引擎，“我要操作这个3D组件”。
    
2. **获取控件**：你告诉引擎，“把这个组件里显示的那个UI界面拿给我”。
    
    - 此时，你拿到的是一个通用的‘UI界面’，引擎还不知道它是血条还是伤害数字。
        
3. **类型转换为 UI_伤害数字 (Cast to...)**：你告诉引擎，“我确定刚才拿出来的这个UI界面，就是我写的那个‘UI_伤害数字’蓝图”。
    
4. **之后（图里还没连的地方）**：一旦转换成功，你就可以从蓝色的引脚拉出线，找到那个 **Text Block（文本框）**，然后设置它的 **Text** 为具体的伤害数值（比如 50）。

## 创建物品吸附节点
![[Pasted image 20251209204446.png]]

**总结一个“万能公式”**
你可以根据**“生命周期”**来决定用不用这个节点：

1. **临时工（用 Attach）：**==一定要注意插槽的使用==
    
    - 飘出的伤害数字（飘完就死）。
        
    - 语言气泡（说完就没）。
        
    - 捡起的武器（可能随时会扔掉换别的）。
        
    - 身上的特效（燃烧Buff，着火了粘在身上，火灭了销毁）。
        
    - **策略：** SpawnActor -> Attach -> 用完 Destroy。
        
2. **正式工（直接加组件）：**
    
    - 头顶常驻血条。
        
    - 角色的名字 ID。
        
    - NPC 的任务问号（如果一直都在）。
        
    - **策略：** 直接在蓝图左上角 Add Component，不用写代码去粘。

## Cast to <蓝图名称>类型转换
 1. 通俗解释：身份的核实与视角的切换
想象你是一个保安（UE5 引擎），你的面前走过来一个人（一个对象/Object）。
- **通用身份（Parent Class）：** 在你眼里，你只知道他是个**“人”**（Actor）。
- **具体身份（Child Class）：** 但这个人可能具体是**“医生”**、**“警察”**或者**“快递员”**。
当你手中拿着一个“人”的引用时，你无法直接命令他“做手术”或者“送快递”，因为你只知道他是人，不知道他是不是医生或快递员。

### 常用的display命令
- 1. 查看当前设备配置
	- \<R1>display current-configuration 或者 disp cu  
- 2. 查看全局系统视图下的配置
	- display this 或者 disp th
- 3. 查看当前配置，设置过滤方式为xxxxx
	- disp current-configuration | xxxxx
	- disp current-configuration | include Gig   // 包含“Gig”字符串
	- disp current-configuration | exclude Gig  //不包含“Gig”
	- disp current-configuration | begin user-interface  //从“user-interface” 开始之后的配置
- 4. 显示时钟
	- display clock
	- clock datetime 8:30:00 2022-11-28     //设置系统日期时间为

                     目标IP  掩码  下一跳IP

 //恢复接口并删除已经配置的路由条目

[R1-GigabitEthernet0/0/3]quit

[R1]undo ip route-static 10.0.1.2 255.255.255.255 10.0.13.3 preference 100

# 四，OSPF路由协议基础实验
![](图片/网络通信-华为/期末速通/IMG-20260526163842285.png)

```
步骤1：设备基础配置
[R1]display ip routing-table    //查询路由表

步骤2： 完成 OSPF 基本配置
[R1]ospf 1        //创建进程，1表示进程号，可以创建多个ospf进程，编不同号码

[R1-ospf-1]area 0   //area命令用来创建OSPF区域，并进入OSPF区域视图

[R1-ospf-1-area-0.0.0.0]network 10.0.12.1 0.0.0.255
[R1-ospf-1-area-0.0.0.0]network 10.0.13.1 0.0.0.255
[R1-ospf-1-area-0.0.0.0]network 10.0.1.1 0.0.0.0
network network-address wildcard-mask用来指定运行OSPF协议的接口。
满足下面两个条件，OSPF协议才能在接口上运行：
1. 接口的IP地址掩码长度≥network命令中的掩码长度。OSPF使用==反掩码==，
例如0.0.0.255表示掩码长度24位
2. 接口的IP地址必须在network命令指定的网段范围之内。
此时三个接口都被使能，同时属于区域0

[R2]ospf
[R2-ospf-1]area 0
[R2-ospf-1-area-0.0.0.0]network 10.0.12.2 0.0.0.0
[R2-ospf-1-area-0.0.0.0]network 10.0.23.2 0.0.0.0
[R2-ospf-1-area-0.0.0.0]network 10.0.1.2 0.0.0.0
当network命令配置的wildcard-mask为全0时，如果接口的IP地址与network-address配置的IP地址相同，则此接口也会运行OSPF协议。

步骤3：查看OSPF状态
#查看OSPF邻居
[R1]display ospf peer

// display ospf peer命令用来显示OSPF中各区域邻居的信息。包括邻居所属的
区域、邻居Router ID、邻居状态、DR和BDR路由器等信息。


[R1]display ip routing-table protocol  ospf
//查看 IP 路由表中由 OSPF 学习到的路由

步骤 4:配置 OSPF 认证
[R1]interface GigabitEthernet0/0/1
[R1- GigabitEthernet0/0/1]ospf authentication-mode md5 1 cipher HCIA-Datacom
[R1]interface GigabitEthernet0/0/3
[R1- GigabitEthernet0/0/3]ospf authentication-mode md5 1 cipher HCIA-Datacom
[R1- GigabitEthernet0/0/3]display this

#进入接口，然后给ospf协议配置认证

[R1]display ospf peer brief 

步骤 5:假设 R1 是所有网络的出口，所以在 R1 上向 OSPF宣告默认路由

[R1]ospf
[R1-ospf-1]default-route-advertise always
//default-route-advertise命令用来将默认路由通告到普通OSPF区域，如果没有配置always参数，本机路由表中必须有激活的非本OSPF默认路由时才向其他路由器发布默认6路由。本例中，本地路由表中没有默认路由，所以需要增加always参数。

[R2]display ip routing-table

步骤 6 通过修改 R1 相应接口的 Cost 值，使得 R1 的 LoopBack0 接口通过 R1->R3->R2 的路
径访问 R2 的 LoopBack0 接口,路由表Cost一列的值

[R1]interface GigabitEthernet0/0/3
[R1- GigabitEthernet0/0/3]ospf cost 10
//进入接口，然后使用ospf cost xx 命令修改，开销越小，越先走那条线
 
[R1]display ip routing-table
[R1]tracert –a 10.0.1.1 10.0.1.2


```

## 其他
- OSPF协议封装在==IP==数据包内
- ==display ospf peer==查看领居，建立后状态==two-way==邻接关系建立后是==Full==
- 缺省情况下，在以太网链路上发送OSPF HELLO报文的周期为==10==秒
- OSPF协议在进行主从关系选举时依据==Router ID==
- OSPF协议用==DD==报文来描述自己的LSDB
- OSPF协议的HELLO报文中不包含==LSA==字段
- VRP支持OSPF多进程，如果在启用OSPF时不指定进程号，则默认使用的进程号为==1==
- 两台路由器运行在PPP链路上，管理员在两台路由器上配置了OSPF单区域，且它们的Router ID相同，则==VRP会提示两台路由器的Router ID冲突==
- ==OSPF协议根据链路状态法计算最佳路由==
- 查看设备OSPF协议配置信息：==display current-configuration==，==在OSPF协议视图下：display this==
- OSPF协议在==广播类型，点到多点==网络类型中需要选举DR和BDR
- ==DR和BDR之间也要建立邻接关系，若两台路由器的优先级值相等，则选择RouterlD大的路由器作为DR，默认情况下，本广播网络中所有的路由器都将参与DR选举==
- 在一台路由器上配置OSPF时，必须手动进行的配置有：==开启OSPF进程，创建OSPF区域，指定每个区域中所包含的网络==
- OSPF协议邻居和邻接关系建立过程中，稳定状态：==Two-way==，==Full==
- OSPF进程的Router ID修改之后==不会立即生效==
- OSPF支持**多区域部署**，==并不要求所有接口都属于同一个区域==
- 骨干区域内的路由器==没有==它所有区域的全部LSDB

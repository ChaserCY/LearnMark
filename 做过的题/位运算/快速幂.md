## 题目描述

给你三个整数 a,b,p，求 abmodp。

## 输入格式

输入只有一行三个整数，分别代表 a,b,p。

## 输出格式

输出一行一个字符串 `a^b mod p=s`，其中 a,b,p 分别为题目给定的值， s 为运算结果。

## 输入输出样例

**输入 #1**复制运行

2 10 9

**输出 #1**复制运行

2^10 mod 9=7

## 说明/提示

**样例解释**

210=1024，1024mod9=7。

**数据规模与约定**

对于 100% 的数据，保证 0≤a,b<231，a+b>0，2≤p<231。

题解：（快速幂,使用位运算拆解指数，不用一次又一次的循环）
```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    long long a,b,p;        // 定义底数a，指数b，模数p
    cin>>a>>b>>p;           // 输入a,b,p
	
	long long A=a,B=b;
	
	a%=p;
	long long res = 1;
	while(b>0){
		
	if(b&1){  //当前b二进制最后一位是否为1，相当于是否为奇数
	res=res*a%p;
	
	}
	a = a*a%p;          //现有变成平方
	b>>=1;              //右移一位，1010->101,相当于除以2
	
	}
    printf("%ll^%ll mod %ll=%ll",A,B,p,res);
    return 0;
}
```

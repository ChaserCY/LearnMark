[104. 二叉树的最大深度](https://leetcode.cn/problems/maximum-depth-of-binary-tree/)

给定一个二叉树 `root` ，返回其最大深度。

二叉树的 **最大深度** 是指从根节点到最远叶子节点的最长路径上的节点数。

**示例 1：**

![](https://assets.leetcode.com/uploads/2020/11/26/tmp-tree.jpg)

**输入：**root = [3,9,20,null,null,15,7]
**输出：**3

**示例 2：**

**输入：**root = [1,null,2]
**输出：**2

**提示：**

- 树中节点的数量在 `[0, 104]` 区间内。
- `-100 <= Node.val <= 100`

题解：（==层层递加+回溯==）
```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(nt x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int maxDepth(TreeNode* root) {
        int count=0;
        int MaxD= 0;
        if(!root)return 0;
        Max_deep(root,count,MaxD);
        return MaxD;
  
    }
    void Max_deep(TreeNode* T,int &count,int &MaxD){
        if(!T){
            return ;}
        count++;
        MaxD = max(MaxD,count);
        Max_deep(T->left,count,MaxD);
        if(T->left!=nullptr)count--;
        Max_deep(T->right,count,MaxD);
        if(T->right!=nullptr)count--;
    }
};
```

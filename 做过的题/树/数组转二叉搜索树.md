[108. 将有序数组转换为二叉搜索树](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/)

给你一个整数数组 `nums` ，其中元素已经按 **升序** 排列，请你将其转换为一棵 平衡 二叉搜索树。

**示例 1：**

![](https://assets.leetcode.com/uploads/2021/02/18/btree1.jpg)

**输入：**nums = [-10,-3,0,5,9]
**输出：**[0,-3,9,-10,null,5]
**解释：**[0,-10,5,null,-3,null,9] 也将被视为正确答案：
![](https://assets.leetcode.com/uploads/2021/02/18/btree2.jpg)

**示例 2：**

![](https://assets.leetcode.com/uploads/2021/02/18/btree.jpg)

**输入：** nums = [1,3]
**输出：**[3,1]
**解释：**[1,null,3] 和 [3,1] 都是高度平衡二叉搜索树。

**提示：**

- `1 <= nums.length <= 104`
- `-104 <= nums[i] <= 104`
- `nums` 按 **严格递增** 顺序排列

题解：（分治+递归）
不断寻找中间的数组值来构建每个子树的根节点，来逐步构建整个子树
```cpp
class Solution { 
public: TreeNode* sortedArrayToBST(vector<int>& nums) { 
int len = nums.size(); 
// 初始调用：左闭右开区间 [0, len) 
return dfs(nums, 0, len); 
} 
private: 
// 建议将辅助函数设为私有，符合封装原则 
TreeNode* dfs(vector<int> &nums, int p_left, int p_right) 
{ 
// 终止条件：左边界 >= 右边界，说明当前区间无元素，返回空节点
 if (p_left >= p_right) return nullptr; 
 // 取区间中点作为根节点（保证平衡） 
 int mid = (p_left + p_right) / 2; 
 TreeNode *root = new TreeNode(nums[mid]); 
 // 递归构建左子树：区间 [p_left, mid) 
 root->left = dfs(nums, p_left, mid); 
 // 递归构建右子树：区间 [mid+1, p_right) （关键修正：mid+1） 
 root->right = dfs(nums, mid + 1, p_right);
  return root;
} 
 };
```

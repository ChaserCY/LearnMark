### 问题描述

小蓝最近在研究一种浮点数的表示方法：R 格式。对于一个大于 0 的浮点数 d，可以用 RR 格式的整数来表示。给定一个转换参数 n，将浮点数转换为 R 格式整数的做法是:

1. 将浮点数乘以 2n；
    
2. 四舍五入到最接近的整数。
    
### 输入格式
一行输入一个整数 nn 和一个浮点数 dd，分别表示转换参数，和待转换的浮点数。
### 输出格式
输出一行表示答案：dd 用 RR 格式表示出来的值。

### 样例输入
```text
2 3.14
```

### 样例输出
```text
13
```

### 样例说明

3.14×22=12.56，四舍五入后为 13。

### 评测用例规模与约定

对于 50% 的评测用例1≤n≤10 将 d 视为字符串时的长度 ≤15

对于 100% 的评测用例：1≤n≤1000 将 dd 视为字符串时的长度 ≤1024；保证 d 是小数，即包含小数点。

题解：(小数位数过多，高精度乘法)
```cpp
#include <bits/stdc++.h>
  
using namespace std;
  
int main(){
  int n;
  string s;
  cin>>n>>s;
  vector<int> a(11000);
  int d=0;              //记录小数点所在索引
  int ant=0;            //统计最长索引
  int p = s.size();     //转换类型t_size
  
for(int i = p-1;i>=0;i--)
{
  if(s[i]=='.'){
    d=ant;                 //标记小数点
  }
  else{
    a[ant++] = s[i]-'0';         //挨个倒序记录数字
  }
}
  
for(int i = 0;i < n;i++){
  for(int j = 0;j<ant;j++){
    a[j]*=2;                    //进行单次整体乘2
    }
    
    for(int j = 0;j<ant;j++){
      if(a[j]>=10){
   a[j+1]+=a[j]/10;
    a[j] = a[j]%10;            //依次进位
      }
   }
   if(a[ant])ant++;          //扩位(乘2专属，太大就不止++)
  }
  
if(a[d-1]>=5){          //四舍五入
a[d]+=1;
for(int i = d;i<ant;i++){
  if(a[i]>=10){
    a[i+1]++;
    a[i] %=10;         //轮流检测进位
  }
if(a[ant]){            //扩位
  ant++；
}
}
}

for(int i = ant-1;i>=d;i--){
  cout<<a[i];            //倒序打印整数部分
}
  return 0;
}
```

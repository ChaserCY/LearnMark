### 问题描述

若一个正整数 x 可以被表示为 p2×q2，其中 p、q 为质数且 p≠q，则 xx 是一个**双子数**。请计算区间 [2333,‭23333333333333‬][2333,‭23333333333333‬] 内有多少个**双子数**？

### 答案提交

这是一道结果填空的题，你只需要算出结果后提交即可。本题的结果为一个整数，在提交答案时只填写这个整数，填写多余的内容将无法得分

## 题解
```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
  long long L=2333,R=23333333333333;
  long long l=ceil(sqrt(L)),r=floor(sqrt(R));
  vector<long long> prime;
  vector<bool> is_prime(r+1,true);
  
  //线性筛，循环必须从2开始
  for(long long i = 2;i<=r;i++){
  
    if(is_prime[i]==true)prime.push_back(i);
    
    for(long long p:prime){
      if(i*p>r)break;//倍数超出限制
      
      is_prime[i*p]=false;//找到合数
      
      if(i%p==0)break;//筛去一些重复的标记
    }
  }
  
  auto count_equeal= [&](long long limit){ //lambda函数
    long long res = 0;
  long long j = prime.size()-1;
//遍历素数数组  
for(long long i = 0;i < prime.size();i++ )
{

  while(j>i&&(long long)prime[i]*prime[j]>limit)j--;//从后往前，总大到小找出最大符合关系的j，j-i可以快速算数量
  
  if(j <= i)break;//剔除
  
  res+=(j-i);
  
}
  return res;
  };
  
  cout << count_equeal(r)-count_equeal(l-1);
  return 0;
}


```

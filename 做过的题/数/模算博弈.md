双十一期间，蓝桥商场根据消费额累计了总金额为 NN 的奖池。 小蓝和小桥成为奖池的最终候选人，需要通过一场游戏决定奖池归属。

游戏规则如下：

- 两人轮流进行操作，小蓝先手。
- 每次操作时，当前玩家可以选择一个数字 xx（1≤x≤91≤x≤9），并从奖池奖金 NN 中减去 xx。
- 率先**将奖金正好减到 00** 的玩家获胜，并获得整个奖池。

假设双方都采取最优策略，请你判断在给定初始奖金 NN 的情况下，谁会获胜。

### 输入格式

输入一行，包含一个整数 NN（1≤N≤1091≤N≤109），表示初始奖池的奖金总额。

### 输出格式

输出一行：

- 如果小蓝获胜，输出 `L`；
- 如果小桥获胜，输出 `Q`;

### 样例输入 1

```
14
```

### 样例输出 1

```
L
```

### 样例输入 2

```
20
```

### 样例输出 2

```
Q
```


题解：（10是必败状态，以此类推，20,30,40...11,12,...必胜）
```cpp
#include <iostream>

using namespace std;

int main()

{

  int N;

  cin>>N;

  if(N%10==0)cout<<"Q";

  else cout<<"L";

  return 0;

}
```

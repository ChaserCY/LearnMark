[42. 接雨水](https://leetcode.cn/problems/trapping-rain-water/)

给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

**示例 1：**

![](https://assets.leetcode-cn.com/aliyun-lc-upload/uploads/2018/10/22/rainwatertrap.png)

**输入：** height = [0,1,0,2,1,0,1,3,2,1,2,1]
**输出：** 6
**解释：** 上面是由数组 [0,1,0,2,1,0,1,3,2,1,2,1] 表示的高度图，在这种情况下，可以接 6 个单位的雨水（蓝色部分表示雨水）。 

**示例 2：**

**输入：** height = [4,2,0,3,2,5]
**输出：** 9

**提示：**

- `n == height.length`
- `1 <= n <= 2 * 104`
- `0 <= height[i] <= 105`

题解1（慢）：
//每个位置分两侧，两侧都求最大值
```cpp
class Solution {
public:
int trap(vector<int>& height) {
        int n = height.size();
        int sum = 0;
        int Max_L = height[0];
        int Max_R = 0;
        map<int,int> Q ;
        for(int i = 1;i<n;i++){
            if(Q.count(height[i])==0){
                Q[height[i]] = 1;
            }
            else{
                Q[height[i]]++;
            }
        }
        for(int i = 1;i < n-1;i++){
            int p = height[i];
            Max_L = max(Max_L, height[i-1]);
                Q[p]--;
                if(Q[p]==0){
                Q.erase(p);
               }
            Max_R = Q.rbegin()->first;
            int T = min(Max_L, Max_R);
            if(T>p){
                sum+=T-p;
            }
        }
        return sum;
    }
};

```

题解2（双指针快）：
//其中的左右最大值，虽然只是两指针两侧的局部最大值，但是给予了循环一种循环迭代规则，这就避免了要直接求两边整个最大值的消耗
```cpp
class Solution {
public:
int trap(vector<int>& height) {
  int n = height.size();
int l = 0, r= n-1;
int max_l = 0, max_r = 0;
int re = 0;
while(l<r){
max_l = max(max_l,height[l]);
max_r = max(max_r,height[r]);
if(height[l]<height[r]){
re += max_l-height[l];
 l++;
}
else{
re += max_r - height[r];
r--;
}
}
return re;
    }
};
```

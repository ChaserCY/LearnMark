# MC0481-丫鬟的月例银
[码蹄集OJ-丫鬟的月例银](https://www.matiji.net/exam/brushquestion/81/4693/305EE97B0D5E361DE6A28CD18C929AF0)
年终结算时，贾母发现各房主子丫鬟的月例银总额太高了。为了削减开支，需要进行调整。现在假设荣国府一共有n个丫鬟，她们的月例银排成正整数序列为a1​∼an​。现在削减开支的目标，是要让这n个数字之和不超过m。

为了实现这一目标，小码妹可以钦定一个正整数D，使得所有的ai​变成，现在问，要实现这一目标，D最小可以是多少（当然不能小于1）？

##### 格式

输入格式：

第一行一个整数T(1≤T≤5×105)，表示测试数据组数，对于每组测试数据：  
第一行两个整数n,m(1≤n≤5×105,1≤m≤1012)。  
第二行nn个整数a1∼an(1≤ai≤109)。  
数据保证 ∑n≤5×105。

输出格式：

对于每组测试数据，一行一个整数，表示答案。

##### 样例 1
输入：
3
5 10
10 10 4 10 6
5 10
1 1 1 1 1
5 10
2 2 3 2 2

输出：
4
1
2

##### 样例 2
输入：
1
1 1
999999999

输出：
500000000

# 题解
```cpp
#include<bits/stdc++.h>
#define int long long
const int mod = 3e5+10;
using namespace std;
  
signed main( )
{
    ios::sync_with_stdio();
    cin.tie(0);
    cout.tie(0);
    int T;
    cin>>T;
    while(T--){
        int n,m;
        cin>>n>>m;
        vector<int> Q(n+1);
        for(int i = 0;i< n;i++){
            cin>>Q[i];
        }
        int l = 1,r = 1e9+10;//确定目标D的上下限
        int ans = 1;
        while(l<=r){
            int mid = (l+r)/2;
            int sum = 0;
            for(int i : Q){
                sum += i/mid; //不能提前求和再除mid，而是分别求和减小误差
            }
            if(sum<=m){
                ans = mid;  //记录符合条件的答案
                r = mid-1;
            }
            else{
                l = mid+1;
            }
        }
  
        cout<<ans<<endl;
    }
    return 0;
}
```

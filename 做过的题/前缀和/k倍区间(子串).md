
### 题目描述

给定一个长度为 NN 的数列，A1,A2,⋯ANA1​,A2​,⋯AN​，如果其中一段连续的子序列 Ai,Ai+1,⋯AjAi​,Ai​+1,⋯Aj​ ( i≤ji≤j ) 之和是 KK 的倍数，我们就称这个区间 [i,j][i,j] 是 K 倍区间。

你能求出数列中总共有多少个 KK 倍区间吗？

### 输入描述

第一行包含两个整数 NN 和 KK( 1≤N,K≤1051≤N,K≤105 )。

以下 N 行每行包含一个整数 AiAi​ ( 1≤Ai≤1051≤Ai​≤105 )

### 输出描述

输出一个整数，代表 K 倍区间的==数目==。

### 输入输出样例

#### 示例

> 输入

`5 2 1 2 3 4 5`

> 输出

```txt
6
```

### 运行限制

- 最大运行时间：2s
- 最大运行内存: 256M

题解：(==使用前缀和，一定一定要注意数据类型要能装下大数据==)
```cpp
#include <iostream>
#include <vector>

//与数的运算有关的子串，使用前缀和解答
//前缀和性质：余数相同的前缀和相减，刚好是能整除的和

using namespace std;
using ll=long long;
int main()
{
  int n,k;
  cin>>n>>k;
  vector<ll> Q(n+1);    //储存前缀和数组
  ll count = 0;
  vector<int> S(100001,0);//储存出现相同余数的次数，然后内的值代表新出现的同余数的搭配子串数，数组大小，与K的值有关
  if(k==0){              //特殊情况
    for(int i = 1;i <= n;i++){
      if(Q[i]==0)count++;
    }
    return count;
  }
  Q[0]=0;
  S[0] = 1;       //余数为0时，有自己当前串这个情况，其他都为0
  for(int i = 1;i <= n;i++){
    cin>>Q[i];
    Q[i]+=Q[i-1];
  
    count+=S[Q[i]%k];  //读取当前前缀和的余数对应次数，然后与同余数的进行组合的次数
		    S[Q[i]%k]++;        //余数数组的次数更新
  }
  cout<<count;
  return 0;
}
```

席间酒过数巡，专诸捧着一盘炙鱼缓步上前，鱼香扑鼻，王僚与左右卫士都被引得目光一晃。谁知专诸近到案前，忽从鱼腹中抽出短剑，寒光一闪直刺吴王；王僚中剑而亡，席上左右惊呼大乱。早已埋伏的甲士立刻冲出护住场面，公子光趁势控住全局——这一击，快、准、狠，讲究的就是“先后次序”，谁先动手，谁后出鞘，半点差池都不行。

现在把这场杀局的“出手先后”抽作一份清单：你手里有三行同样长为n的正整数——可看作三种关键因素的强弱：

•第一行为a1∼an：专诸出手的“劲力”；  
•第二行为b1∼bn​：鱼盘掩护的“时机”；  
•第三行为c1∼cn​：甲士控场的“助势”。

你从这三行里各挑一个数，组成一个三元组(ai​,bj​,ck​)。这一套配合的“杀招分量”定义为它们的乘积：ai×bj×ck。

显然总共有n3n3种不同的三元组可选，但席上一瞬生死，最怕的是“分量太轻”——出手不够、遮掩不密、控场不稳，都会坏事。因此你要把所有n3种配合的分量都算出来，按从小到大排好，问其中值最小的前m个分别是多少（也就是第1小、第2小……直到第m小的乘积值）。

##### 格式

输入格式：

第一行一个整数T(1≤T≤105)，表示测试数据组数。  
对于每组测试数据：  
第一行两个整数n,m(1≤n≤105,1≤m≤min⁡(n3,2×n))
第二行n个整数，分别表示a1∼an(1≤ai≤105)
第三行n个整数，分别表示b1∼bn(1≤bi≤105)
第四行n个整数，分别表示c1∼cn(1≤ci≤105)

保证每个测试点内TT组数据的nn的和不超过105105。

输出格式：

对于每组测试数据：  
输出一行m个整数，其中第ii个整数表示权值第i小的三元组的权值。

##### 样例 1
```text
输入：

1
2 3
1 1
2 2
1 1
```

```
输出：

2 2 2
```
##### 样例 2

输入：

1
3 5
1 2 3
1 2 3
1 1 1

复制

输出：

1 1 1 2 2

复制

##### 备注

对于样例1，显然任何一个三元组的权值都为2，所以答案全部是2。  
对于样例2，选出乘积为11的方案数为3（a数组选第1个，b数组选第1个，cc数组可以选任意一个），而选出乘积为2的方案数大2，由于只需要前5个，故答案为1 1 1 2 2

## 题解：（多组数组找最小值，乘积的最小值，限定个数）
```cpp
//从小到大排序，依次添加搭配，找乘积的最小值
#include<bits/stdc++.h>

using namespace std;
using ll = long long;
  
struct Node{
    ll val;
    int i,j,k;
  
    bool operator<(const Node &other)const{
        return val>other.val;
    }
  
};

  
int main( )
{  
    ios::sync_with_stdio(false);
    cin.tie(0);  
    int T;
    cin>>T;
    while(T--){
        int n;
        int m;
        cin>>n>>m;
    vector<int> a(n);
    vector<int> b(n);
    vector<int> c(n);
    for(int i = 0;i<n;i++)cin>>a[i];
    for(int i = 0;i<n;i++)cin>>b[i];
    for(int i = 0;i<n;i++)cin>>c[i];
    sort(a.begin(),a.end());
    sort(b.begin(),b.end());
    sort(c.begin(),c.end());
  
    priority_queue<Node> pq;
  
    set<tuple<int,int,int>> visited;
  
    pq.push({1ll*a[0]*b[0]*c[0],0,0,0});
    visited.insert({0,0,0});
  
    vector<ll> res;
  
    while(res.size()<(size_t)m&&!pq.empty()){
        Node cur = pq.top();
        pq.pop();  
        res.push_back(cur.val);


        int i = cur.i,j=cur.j,k = cur.k;
  
        if(i+1<n&&visited.count({i+1,j,k})==0){
            pq.push({1ll*a[i+1]*b[j]*c[k],i+1,j,k});
            visited.insert({i+1,j,k});
        }
        if(j+1<n&&visited.count({i,j+1,k})==0){
            pq.push({1ll*a[i]*b[j+1]*c[k],i,j+1,k});
            visited.insert({i,j+1,k});
        }
        if(k+1<n&&visited.count({i,j,k+1})==0){
            pq.push({1ll*a[i]*b[j]*c[k+1],i,j,k+1});
            visited.insert({i,j,k+1});
        }
  
    }
    for(int i = 0;i < m;i++){
        cout<<res[i]<<(i==m-1?"":" ");
    }
    cout<<endl;
    }
    return 0;
}
```

 我们称一对正整数 (a,b)(a,b) 是“特别互素对”，如果满足以下条件：

1. 1⩽a<b⩽1061⩽a<b⩽106。
2. aa 与 bb 互素，即 aa 和 bb 的最大公约数为 1。
3. a+ba+b 是 2025 的倍数。

请计算一共有多少对 (a,b)(a,b) 是“特别互素对”。


```cpp
#include <iostream>
 using namespace std; 
 int gcd(int a, int b) 
 { 
 return b == 0 ? a : gcd(b, a % b); 
 } 
 //**递归 + 欧几里得算法**实现的「最大公约数」
 int main() 
 { 
 int n = 1000000, res = 0; 
 for (int i = 1; i <= n; i++) 
 { 
 for (int j = 2025 - i; j <= n; j += 2025)//
  {  
  if ((j > i) && gcd(i, j) == 1) res++; 
   }  
   }  
   cout << res << endl; 
   cout << 93816892 << endl; return 0; 
   }
```

#### 题目描述

给定一个包含 n 个节点的无向图中，节点编号从 1 到 n （含 1 和 n ）。

你的任务是判断是否有一条从节点 source 出发到节点 destination 的路径存在。

###### 输入描述

第一行包含两个正整数 N 和 M，N 代表节点的个数，M 代表边的个数。 

后续 M 行，每行两个正整数 s 和 t，代表从节点 s 与节点 t 之间有一条边。 

最后一行包含两个正整数，代表起始节点 source 和目标节点 destination。

###### 输出描述

输出一个整数，代表是否存在从节点 source 到节点 destination 的路径。如果存在，输出 1；否则，输出 0。

###### 输入示例

```
5 4
1 2
1 3
2 4
3 4
1 4
```
###### 输出示例

```
1
```

## 题解：（包含并查集的模板）
```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
vector<int> ddr;
int n,m;
  
void init(){
    for(int i = 1;i<=n;i++){
        ddr[i] = i;
    }
}
int find(int t){
    if(ddr[t]==t)return t;
     return ddr[t] = find(ddr[t]);
}
  
void add_(int u,int v){
    v = find(v);
    u = find(u);
    if(v==u)return;
    ddr[u] = v;
}
  
  
bool is_com(int u,int v){
    v = find(v);
    u = find(u);
    return v==u;
}
  
int main(){
    cin>>n>>m;
    ddr.resize(n+1);
    init();
    for(int i = 0;i< m;i++){
        int a,b;
        cin>>a>>b;
        add_(a,b);
    }
    int s,d;
    cin>>s>>d;
    if(is_com(s,d)){
        cout<<1;
    }
    else cout<<0;

    return 0;
}
```

# 组合数
标准求组合数
```cpp
const int MOD = 998244353;

//快速幂处理此方
ll qpow(ll a, ll b) {  
ll res = 1;  
while(b) {  
if(b & 1) res = res * a % MOD;  
a = a * a % MOD;  
b >>= 1;  
}  
return res;  
}  

  
// 预处理阶乘和逆元  
void init(int n) {  
fact[0] = 1;  
for(int i = 1; i <= n; i++) fact[i] = fact[i-1] * i % MOD;//求正向阶乘数组(取过MOD的)  
invfact[n] = qpow(fact[n], MOD - 2);  //费马小定理，a^(−1)≡a^(MOD−2)
for(int i = n-1; i >= 0; i--) invfact[i] = invfact[i+1] * (i+1) % MOD;  //倒推
}  
  
// 组合数  
ll C(int n, int k) {  
if(k < 0 || k > n) return 0;  
return fact[n] * invfact[k] % MOD * invfact[n-k] % MOD;  
}
```

# 前缀和与差分
假设原数组：`a[1],a[2],a[3],a[4]`

### ① 前缀和数组 s

公式：\(s[i] = a[1]+a[2]+...+a[i]\)

- 输入：**原始数组 a**
- 输出：前缀和 s
- 用途：随便问区间 `[L,R]` 的和：\(s[R]-s[L-1]\)
    
    👉 **作用：查询**

### ② 差分数组 d

公式：\(d[1]=a[1],\ d[i]=a[i]-a[i-1]\)

- 输入：**原始数组 a**，可以算出 d
- 但我们竞赛真正的用法是反向用：
    
    先操作 d（区间更新只改 2 个点），**最后对 d 求前缀和，还原出 a**
    
    👉 **作用：批量区间修改**

## 2. 关键关系：互逆

- 对原数组 a 求【差分】得到 d
- 对 d 求【前缀和】会变回原来的 a

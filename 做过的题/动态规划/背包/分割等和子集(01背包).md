给你一个 **只包含正整数** 的 **非空** 数组 `nums` 。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

**示例 1：**

输入：nums = [1,5,11,5]
输出：**true
解释：数组可以分割成 [1, 5, 5] 和 [11] 。

**示例 2：**

**输入：nums = [1,2,3,5]
输出：false
解释：数组不能分割成两个元素和相等的子集。

**提示：**

- `1 <= nums.length <= 200`
- `1 <= nums[i] <= 100`

# 题解
```cpp
class Solution {
public:
    bool canPartition(vector<int> &nums)
{
    int sum = accumulate(nums.begin(), nums.end(), 0);//数组求和函数
    if (sum % 2 == 1)  //如果是和为奇数显然无法分成两个等和子集
        return false;
        
    int target = sum/2;  //背包总容量(凑数组一半和就满足题要求了)
    vector<bool> dp(target+1,false);  //dp[i]表示和为i的情况能不能凑出来
    dp[0]=true;
    for(int num:nums){ //外：遍历数组元素
        for(int i = target;i>=num;i--){ //内：遍历倒序遍历和情况
            dp[i] = dp[i]||dp[i-num];  //选vs不选当前数组元素
        }
    }
    return dp[target];
}
};
```

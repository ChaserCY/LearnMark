# LearnMark

个人学习笔记仓库，用 [Obsidian](https://obsidian.md) 维护，记录编程语言、游戏开发、AI 工具链等方向的学习过程和踩坑记录。

| --- | --- |
| `AI` | Claude Code / Skill / MCP、工作流、常用 AI 工具 |
| `C++` | C++ 语言基础、C++ Primer Plus、并发与多线程 |
| `Java` / `JavaEE` | Java 基础、JavaEE 期末项目 |
| `Linux` | Linux 常用命令与系统知识 |
| `UE` | 虚幻引擎、PuerTS、GAS |
| `做过的题` | 算法题解（二分、位运算等） |
| `数据库SQL Server` | SQL Server / MySQL 笔记 |
| `网络通信-华为` | 华为网络认证相关笔记 |
| `协作工具` | Perforce 等协作工具的使用 |
| `素材网站` | 游戏开发素材与策划资料 |
| `图片` | 笔记配图 |

## 使用说明

这是一个 Obsidian 库，笔记中的图片分散存放在各目录下的 `图片/` 子目录中。

图片使用 **Git LFS** 管理，克隆前请先安装 [Git LFS](https://git-lfs.com)：

```bash
git lfs install
git clone https://github.com/ChaserCY/LearnMark.git
```

如果已经克隆但图片是几行文本（LFS 指针）而非图片，补拉一下：

```bash
git lfs pull
```

# 智能指针
==std::unique_ptr=**裸指针**+**自动销毁**+**禁止复制**==
C++11 标准库（`<memory>` 头文件）提供了三种智能指针，分别应对不同的场景。
#### 1. `std::unique_ptr` （独占型）

**“这块内存是我的，谁也别想抢。”**//在}结束后，自动释放
这是最常用的智能指针（占 80% 场景）。它保证同一时刻只能有一个指针拥有这块内存。

- **特点**：
    - **不能复制**（你不能 `t2 = t1`，否则会有两个主人，乱套了）。
    - **只能移动**（`std::move`），所有权转移。
    - **轻量级**：性能和裸指针几乎一样，没有额外开销。
- **代码示例**：
```cpp  
    #include <memory>

    void testUnique() {
        // 创建方式：推荐使用 std::make_unique (C++14)
        std::unique_ptr<int> ptr1 = std::make_unique<int>(100);
    
        // std::unique_ptr<int> ptr2 = ptr1; // ❌ 报错！禁止复制
        
        // 所有权转移：ptr1 变空了，ptr2 接管内存
        std::unique_ptr<int> ptr2 = std::move(ptr1); 
    
        // 离开作用域时，ptr2 自动释放内存，ptr1 因为是空的啥也不干
    }
```

#### 2. `std::shared_ptr` （共享型）
**“这块内存是我们大家的，最后一个走的记得关灯。”**
这就是能解决你刚才多线程崩溃问题的神器。
- **特点**：
    - **引用计数**：内部维护一个计数器。每多一个指针指向这块内存，计数器 +1；销毁一个指针，计数器 -1。
    - **自动销毁**：当计数器变为 0 时，真正的内存才会被释放。
    - **可复制**：可以传给函数、传给线程，大家一起用。
- **代码示例**：
```cpp
    void testShared() {
        // 创建方式：推荐 std::make_shared
        std::shared_ptr<int> ptr1 = std::make_shared<int>(200); 
        // 此时计数 = 1
    
        {
            std::shared_ptr<int> ptr2 = ptr1; 
            // 此时计数 = 2 (ptr1 和 ptr2 共享)
            std::cout << *ptr2 << endl; 
        } // ptr2 离开作用域，计数 -1，现在计数 = 1
    
        // ptr1 依然活着，内存没释放
    } // ptr1 离开作用域，计数 = 0 -> 释放内存！
```
    
- **回到你的多线程问题**：  
    如果你把 `int a` 换成 `std::shared_ptr<int> a`，然后按值传递给线程。线程会持有一份计数。即使主线程结束了，只要子线程还握着这个指针（计数 > 0），内存就不会释放，程序就不会崩！
    

#### 3. `std::weak_ptr` （旁观者）
**“我就静静地看着，不参与管理。”**
它是为了配合 `shared_ptr` 而存在的，专门解决**“循环引用”**导致的死锁问题。
- **场景**：对象 A 里面有个 `shared_ptr` 指向 B，对象 B 里面有个 `shared_ptr` 指向 A。
    - 结果：A 等 B 释放才释放，B 等 A 释放才释放。谁也死不了，内存永远泄漏。
- **用法**：`weak_ptr` 指向 `shared_ptr` 管理的对象，但**不增加引用计数**。如果想用数据，必须先“转正”变成 `shared_ptr`（检测对象是否还活着）。

# &
### 1. 身份一：引用（Reference）

**口诀：出现在“类型”旁边，就是引用。**

当你定义一个变量，或者在函数参数列表里看到 `&` 时，它表示**“别名”**。它不是取地址，也不产生新内存，只是给已有的变量起个外号。

- **特征**：紧跟着类型（如 `int&`、`float&`、`MyClass&`）。
    
- **位置**：通常在赋值号 `=` 的左边，或者函数的参数里。
    
```cpp
int a = 100;

// 【引用】
// 这里的 & 紧挨着类型 int，意思是 b 是 a 的“分身”
int& b = a; 

b = 200; // 修改 b 就是修改 a
// 此时 a 也变成了 200
```

**函数参数中的例子：**
```cpp
// 【引用】
// 这里的 & 表示 x 不是副本，就是调用者传进来的那个变量本身
void func(int& x) { 
    x++; 
}
```

---

### 2. 身份二：取地址（Address-Of）

**口诀：出现在“变量”旁边，就是取地址。**

当你想知道一个变量在内存里的门牌号（也就是指针指向的值）时，用这个。

- **特征**：前面没有类型，直接放在已经存在的变量名前面。
    
- **位置**：通常在赋值号 `=` 的右边。

```cpp
int a = 100;

// 【取地址】
// 这里的 & 放在变量 a 前面，意思是“获取 a 的内存地址”
// 结果必须存到一个指针（int*）里
int* p = &a; 

// 此时 p 的值可能是 0x7ffd8a...（一个十六进制的内存地址）
```

---
### 3. 身份三：按位与（Bitwise AND）

**口诀：夹在两个“数字/变量”中间，就是数学运算。**

这是逻辑运算，跟指针和引用都没关系。

- **特征**：左右两边都是东西（数字或变量）。
    
```cpp
int x = 5; // 二进制 101
int y = 3; // 二进制 011

// 【按位与】
// 夹在中间，做二进制运算：101 & 011 = 001
int z = x & y; 
```

---

### ⚡️ 终极分辨图解（一张图看懂）

请看这一行最令人迷惑的代码：
```cpp
int* p = &a;
```

我们要把它拆开看：

1. **左边 `int*`**：这是在定义**类型**，告诉编译器 `p` 是一个**指针**。
    
2. **右边 `&a`**：这是在做**动作**，表示**取出 `a` 的地址**。


```cpp
int& b = a;
```

1. **左边 `int&`**：这是在定义**类型**，告诉编译器 `b` 是一个**引用**。
    
2. **右边 `a`**：把 `a` 这个人绑在 `b` 这个名字上。
    

---

### 总结口诀（建议背诵）

| 代码长相     | 这里的 `&` 是什么？          | 含义               |
| -------- | --------------------- | ---------------- |
| `int& x` | **引用** (Reference)    | 定义一个别名。          |
| `&x`     | **取地址** (Address-Of)  | 获取变量的内存地址（给指针用）。 |
| `x & y`  | **按位与** (Bitwise AND) | 数学运算（二进制与）。      |
| `x && y` | **逻辑与** (Logical AND) | 逻辑判断（并且）。        |

**一句话心法：**  
**“左类引用，右变取址。”**  
（定义类型时在左边是引用，操作变量时在右边是取地址）




# 友元friend
`friend`（友元）是 C++ 中一个**打破封装**的关键字。
==友类，友类外函数，友类中函数==
它的作用非常霸道：**让一个外人，可以随意访问我私藏的“秘密”（即 `private` 和 `protected` 成员）。**

通常在面向对象编程（OOP）中，`private` 成员是绝对禁止外部访问的。但有时候为了方便（或者迫不得已），我们需要给某个“好朋友”开个后门，这就用到了 `friend`。

`friend` 主要有三种用法，按常用程度排序：

---
### 1. 友元函数 (Friend Function) —— 最常用

**场景**：你需要定义一个普通的全局函数（不是类的成员函数），但这个函数需要读取或修改某个类的私有数据。

**最经典案例：重载 `<<` (cout) 运算符**  
`std::cout` 是 C++ 标准库的东西，它不可能成为你自定义类的成员函数。所以，为了能写 `cout << myObj;`，你必须把这个运算符函数声明为“友元”。

```cpp
#include <iostream>

class Box {
private:
    int secretValue = 999; // 私有数据，外人不可见

public:
    // 声明友元函数
    // 意思是：printBox 这个函数虽然不是我家人，但我允许它看我的秘密
    friend void printBox(Box& b);
};

// 这是一个普通的全局函数
void printBox(Box& b) {
    // 因为它是 friend，所以它可以直接访问 b.secretValue
    // 如果没有 friend，这行代码会报错！
    std::cout << "The secret is: " << b.secretValue << std::endl;
}

int main() {
    Box b;
    printBox(b); // 输出 999
    return 0;
}
```

---
### 2. 友元类 (Friend Class) —— 关系户

**场景**：你有两个类，关系非常紧密（比如 `Manager` 类需要管理 `Worker` 类的所有内部细节）。你想让类 B 的所有成员函数都能访问类 A 的私有成员。

**用法**：

- **单向的**：A 声明 B 是朋友，B 可以访问 A。但 A 不能访问 B（除非 B 也声明 A 是朋友）。
    
- **不传递**：朋友的朋友不是朋友。
    
```cpp
class Worker {
private:
    int salary = 5000;

    // 声明 Manager 是我的朋友
    // Manager 里的所有方法都可以访问我的 private
    friend class Manager; 
};

class Manager {
public:
    void adjustSalary(Worker& w, int newSalary) {
        // Manager 可以直接修改 Worker 的私有成员 salary
        w.salary = newSalary; 
    }
};
```

---

### 3. 友元成员函数 (Friend Member Function) —— 精确打击

**场景**：你只想让另一个类中的**某一个特定函数**成为朋友，而不是整个类。这是一种更精细的控制，但在 C++ 中写起来比较麻烦（涉及到前向声明和头文件顺序），所以用得比较少。

```cpp
class Worker; // 前向声明

class Manager {
public:
    void adjustSalary(Worker& w); // 先声明
};

class Worker {
private:
    int salary = 5000;
    
    // 只把 Manager::adjustSalary 这一特定函数当朋友
    friend void Manager::adjustSalary(Worker& w);
};
```

---

### ⚠️ 慎用 `friend`！

虽然 `friend` 很方便，但在 C++ 最佳实践中，**能不用尽量不用**。

**为什么？**

1. **破坏封装性**：OOP 的核心就是“隐藏细节”。`friend` 就像在墙上开了个洞，开得多了，墙就不存在了。
    
2. **耦合度过高**：一旦你修改了 A 类的私有成员名字，所有声明为 friend 的 B 类代码全都要改。

**什么时候该用？**

1. **运算符重载**（如 `operator<<`, `operator>>`）。
    
2. **单元测试**：测试代码需要验证类的私有状态时，可以把测试类设为 friend。
    
3. **紧密协作的类**：如链表节点（Node）和链表（List），Node 的私有数据只给 List 看。

**一句话总结：**  
`friend` 是给必须要看你隐私的“特权阶级”发的通行证，发的时候要慎重。

# 线程安全
- 一般来说：
	如果多线程程序每一次的运行结果和单线程运行的结果始终是一样的那么你的线程就是安全的

- **线程安全 (Thread Safety)** 指的是：
	当多个线程同时访问某个类（或函数、对象）时，**无需**调用方进行额外的同步措施（如手动加锁），该代码依然能表现出**正确**的行为，且内部数据保持**一致性**。

-  一句话总结：
	**线程安全就是通过控制“共享可变状态（Shared Mutable State）”的访问，消灭“数据竞争**


# C++ std::mutex
### 1. 本质 (What is it?)

- **互斥量 (Mutual Exclusion)**：一个“令牌”。
    
- **作用**：保护**临界区 (Critical Section)**，确保同一时间只有一个==线程==能访问共享资源（如全局变量、文件写入）。
    
- **特性**：**不可拷贝**（你不能复制一把锁，只能引用它）。
    
---
### 2. 原始操作 (Raw API)

_不推荐在现代 C++ 中直接裸写，容易写出 Bug。_
定义：std::mutex m;
- **`m.lock()`**：尝试拿锁。如果锁被别人拿着，当前线程**阻塞（睡觉等待）**。
    
- **`m.unlock()`**：释放锁。**必须**与 `lock()` 成对出现。
    
- **`m.try_lock()`**：尝试拿锁。
    
    - 拿到了 -> 返回 `true`。
        
    - 没拿到 -> 返回 `false`（**不阻塞**，直接向下执行）。
        

---

### 3. 智能管理 (RAII Wrappers) —— **核心考点**

_C++ 的黄金法则：利用对象生命周期自动管理锁，防止忘记 unlock 或异常导致死锁。_

| 类型                     | 特点                                       | 适用场景                                             |
| ---------------------- | ---------------------------------------- | ------------------------------------------------ |
| **`std::lock_guard`**  | **最轻量**。构造时锁，析构时解。**不可中途手动 unlock**。     | 90% 的简单场景（如保护一个变量自增）。                            |
| **`std::unique_lock`** | **灵活**。构造时锁，析构时解。**可以中途手动 unlock/lock**。 | 需要配合条件变量 (`condition_variable`) 使用，或锁的粒度需要精细控制时。 |
| **`std::scoped_lock`** | **C++17 神器**。可以同时锁住多个 mutex，**自动防死锁**。   | 需要同时锁住 `m1`, `m2`... 的场景。                        |

---

### 4. 死锁 (Deadlock)

- **成因**：
    
    1. **忘记解锁**：`lock()` 后发生异常或 `return`，没跑到 `unlock()`。 -> **解法：用 RAII (`lock_guard`)**。
        
    2. **顺序冲突 (ABBA)**：线程 A 锁 `m1->m2`，线程 B 锁 `m2->m1`。 -> **解法：保证加锁顺序一致**。
        
- **一行代码解决死锁 (C++17)**：
    
    cpp
    
    ```cpp
    // 自动按安全算法同时锁住 m1 和 m2
    std::scoped_lock lock(m1, m2); 
    ```
    

---

### 5. 性能原则 (Performance)

- **锁的粒度 (Granularity)**：
    
    - **锁太粗**（大锁）：把整个函数都锁住 -> 安全,但慢，变成了串行程序。
        
    - **锁太细**（小锁）：只锁那一行修改数据的代码 -> 并发度高，但逻辑复杂。
        
- **原则**：**临界区越小越好**。只在真正修改共享数据的那一瞬间加锁，耗时的操作（如 I/O、复杂计算）尽量移到锁外面。
    

---

### 6. 常见变种 (Variants)

- **`std::recursive_mutex` (递归锁)**：允许**同一个线程**多次 `lock` 同一把锁而不死锁。
    
    - _评价_：如果你需要用到它，通常说明你的代码设计有问题（函数调用层级太乱）。
        
- **`std::shared_mutex` (读写锁，C++17)**：
    
    - **读锁 (`shared_lock`)**：允许多个线程同时读（并发读）。
        
    - **写锁 (`unique_lock`)**：只允许一个线程写（独占）。
        
    - _适用_：**读多写少**的场景（如缓存系统）。

# operator
- 概念：运算符本质是 “函数的语法糖”。`operator` 关键字的作用就是把运算符 “包装” 成函数，让你可以为自定义类重新定义它的行为。
![](图片/C++/知识/IMG-20260120232433548.png)
- 格式：
	类名 operator<符号> (一个或多个类实例){
	详细操作内容.....
	}
### 常见使用场景

#### 1. 重载「赋值运算符」（你之前遇到的场景）

`operator=` 是每个类默认会生成的成员函数，作用是把一个对象的状态复制给另一个对象。

```
class Log {
public:
    // 拷贝赋值运算符（默认生成，这里显式删除）
    Log& operator=(const Log& log) = delete;
};
```

- `Log&` 是返回值类型（返回当前对象的引用，支持链式赋值 `a = b = c`）。
- `(const Log& log)` 是参数（要赋值的源对象，通常用 `const` 引用避免拷贝）。
- `= delete` 表示禁止这个运算符的默认行为，也就是**禁止对象赋值**。

---

#### 2. 重载「二元运算符」（如 `+`、`-`、`==`）

以 `operator+` 为例，实现两个自定义对象的 “相加”：

```
class Point {
    int x, y;
public:
    Point(int x = 0, int y = 0) : x(x), y(y) {}

    // 成员函数形式：左操作数是当前对象（this）
    Point operator+(const Point& other) const {
        return Point(x + other.x, y + other.y);
    }

    // 全局函数形式（适合对称运算符，如 +、==）
    friend Point operator-(const Point& a, const Point& b) {
        return Point(a.x - b.x, a.y - b.y);
    }
};

// 使用示例
Point a(1, 2), b(3, 4);
Point c = a + b; // 等价于 a.operator+(b)
Point d = a - b; // 等价于 operator-(a, b)
```

---

#### 3. 重载「一元运算符」（如 `++`、`!`、`*`）

以自增运算符 `++` 为例，区分前置和后置：

```
class Counter {
    int count = 0;
public:
    // 前置 ++（返回引用，支持链式操作）
    Counter& operator++() {
        count++;
        return *this;
    }

    // 后置 ++（用 int 占位符区分，返回临时对象）
    Counter operator++(int) {
        Counter temp = *this;
        count++;
        return temp;
    }
};

// 使用示例
Counter c;
++c;   // 调用 operator++()
c++;   // 调用 operator++(int)
```

---

#### 4. 重载「特殊运算符」（如 `[]`、`()`、`->`）

这些运算符必须作为**成员函数**重载，常见于容器、函数对象等场景：

cpp

运行

```
class MyArray {
    int data[5] = {1,2,3,4,5};
public:
    // 重载 []，支持数组式访问
    int& operator[](int index) {
        return data[index];
    }
};

// 使用示例
MyArray arr;
cout << arr[2]; // 等价于 arr.operator[](2)，输出 3
```

---

#### 5. 定义「类型转换函数」

让自定义类可以隐式 / 显式转换为其他类型：

cpp

运行

```
class MyInt {
    int value;
public:
    MyInt(int v) : value(v) {}

    // 转换为 int 类型
    operator int() const {
        return value;
    }
};

// 使用示例
MyInt num(10);
int x = num; // 自动调用 operator int()，x = 10
```

---

### 📌 关键规则

1. **必须作为成员函数的运算符**：`operator=`、`operator[]`、`operator()`、`operator->`、`operator*`（指针解引用）等。
2. **可以全局重载的运算符**：`operator+`、`operator-`、`operator==`、`operator<<`（流输出）等（通常需要 `friend` 访问私有成员）。
3. **禁止重载的运算符**：`::`（作用域解析）、`.`（成员访问）、`.*`（成员指针访问）、`?:`（三目运算符）。
